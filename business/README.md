# Изменения предпринимателя

Инициализируйте профиль из корня репозитория командой `npm run init:project -- sever-coffee "Кофейня Север"`. Проверьте `project.json` и сохраните его в Git вашего бизнеса. Публичное имя и идентификатор можно хранить в репозитории. Модель и доступы к внешним системам настраивает администратор каждого окружения отдельно.

Новые компоненты бизнеса, подключения CRM и правила записи кладите в `extensions/`. Для виджета выделите своё имя типа и версию схемы. Подключите реализацию в перечне поддерживаемых возможностей каждого нужного клиента. Сохраните фикстуру, проверку разрешённых действий и поведение для установленного приложения со старым контрактом.

При обновлении upstream проверяйте изменения общих контрактов и миграции. Изменение собственной реализации расширения приезжает из истории форка. Если требуется правка ядра, оформите её отдельным коммитом и оцените, можно ли передать её автору базы без данных бизнеса.
