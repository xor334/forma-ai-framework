# Программа лояльности кофейни

Владелец исходного формата `coffee.loyalty@1` — команда кофейни. Она задаёт число баллов за заказ, стоимость награды и описание в `offer.json`. Адаптер проверяет поля, вычисляет число заказов до первой награды и добавляет готовый блок `forma.text@1` в копию черновика. Публичный релиз содержит только текст предложения. Действий и доступов к данным покупателей у блока нет.

Из корня репозитория:

```bash
node business/extensions/loyalty/compile.mjs examples/coffee/page.json business/extensions/loyalty/offer.json > coffee-loyalty.json
node packages/widget-contract/render.mjs coffee-loyalty.json > coffee-loyalty.html
node packages/widget-contract/release.mjs coffee-loyalty.json
node --test business/extensions/loyalty/loyalty.test.mjs
```

Откройте `coffee-loyalty.html`. В исходной конфигурации награда стоит 100 баллов, заказ приносит 20. Поменяйте начисление на 40, повторите сборку, и в блоке появятся три заказа до награды. В каждой сборке подавайте исходный черновик. Повторяющийся ID останавливает компиляцию и сохраняет существующее содержимое.

Расширение описывает общие условия акции. Персональные балансы и списание наград потребуют серверного учёта и авторизации. Если проекту понадобится новый интерактивный элемент, команда реализует и выпустит соответствующие клиенты, а для уже установленных версий укажет допустимую замену.
