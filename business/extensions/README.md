# Расширения проекта

Отдельный подкаталог на интеграцию или новый виджет. В первом рабочем изменении укажите владельца, версию контракта, разрешённые действия и проверки совместимости. Пакет получает данные и доступы через узкий интерфейс, предоставленный хостом. Данные клиентов, токены, пароли и ключи подписи сюда не помещают.
