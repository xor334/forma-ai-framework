# История базы

## 0.1.0 · Архитектурный прототип

Первый срез поставки содержит документацию по самостоятельным форкам, инициализацию бизнес-профиля, демонстрацию контрактов виджетов, контрольный пример сайта и тесты. Каналы, хранилища и права описаны как архитектурные решения для реализации.

Для каждого следующего выпуска автор указывает поддерживаемые версии контрактов, миграции, затронутые каналы, границы отката и исправленные уязвимости. Предприниматель сохраняет собственную версию и журнал фактически внедрённых релизов.
